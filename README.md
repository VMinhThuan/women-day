# 🪐 Trạm Không Gian 20/10 Gửi Hành Tinh Chị Nhi ✨

Dự án web hiệu ứng chúc mừng ngày Phụ nữ Việt Nam 20/10 dành riêng cho **Chị Nhi**, phong cách Cosmic / Galaxy / Universe với hiệu ứng sao băng, cổng warp speed, âm thanh không gian và thông điệp gỡ sượng cực kỳ tinh tế, duyên dáng!

---

## 📂 Cấu trúc thư mục

```
chuc-20-10-chi-nhi/
├── index.html        # Giao diện chính (Cổng không gian & Trạm vũ trụ)

```

---

## 🚀 Cách mở và chạy

1. **Mở trực tiếp trên máy**:
   - Double-click vào file `index.html` để mở ngay trên trình duyệt (Chrome, Safari, Edge, v.v.).

2. **Chạy server local**:
   ```bash
   python3 -m http.server 8089
   ```
   Sau đó mở: `http://localhost:8089`

3. **Deploy lên mạng miễn phí để lấy link gửi cho Chị Nhi (mở trên điện thoại)**:
   - **Cách 1 (Vercel - Nhanh nhất)**:
     ```bash
     npx vercel
     ```
     (Chỉ cần bấm Enter theo các bước là có ngay link dạng: `https://chuc-20-10-chi-nhi.vercel.app` gửi cho chị Nhi mở trên smartphone mượt mà!)
   - **Cách 2 (Netlify Drop)**:
     Kéo thả cả thư mục này vào https://app.netlify.com/drop để lấy link trong 30 giây.
   - **Cách 3 (GitHub Pages)**:
     Tạo repo trên GitHub, push code lên và bật GitHub Pages trong phần Settings.
